# Precision attribution

Background for [Precision](../frontiers/precision.md).

For the [five public apps at the lab pins](https://github.com/bunnykong/roundhouse-fixpoint-lab/blob/d824c4355c7faae4b9bb4a77b25daa178a3df36c/corpus/apps.json), main `194f26cf` versus S3 `92844f68`, pair expressions within each app by
normalized app-relative file, byte start/end, and kind. Resolve duplicate buckets using owner,
symbol, root, and traversal occurrence, never inferred type. Report unmatched and ambiguous rows
separately from missing annotations. Ablations measure sensitivity: scheduling, join, and slot
effects overlap, so allocating each loss to its first recovering control depends on the declared
priority. Recovering a category can discard possible runtime values or worsen other rows.
Recovery counts and eligible guard paths are not established sound-repair counts.
